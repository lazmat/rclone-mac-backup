rclone Mac backup

This is a personal-use Google Cloud OAuth client for rclone on one Mac. It backs up local files to Google Drive. It is not a product, not shared with the public, and has a single user (the owner).

Google Cloud project: rclone-backup-502607.

What it does

  • Lets rclone on this user’s Mac read and write files in that user’s Google Drive.
  • Used only for encrypted restic snapshots and one-way archives.
